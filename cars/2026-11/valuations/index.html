← Back to shortlistHow to read these numbers

Model-year UK used-car price reference for the November 2026 shortlist. Each row is a snapshot of advertised asking prices, with source, cohort size and typical mileage, rather than a guaranteed value for a particular registration.

Important: This is not a Parkers trade/retail valuation and not an automatic-only comparison. Source: AutoUncle's publicly displayed UK listings data, with year-level average asking price, 5th–95th percentile asking-price range, median mileage and number of adverts. Manual/diesel, specification and damaged/imported examples may be present. Figures were checked between 16 and 20 November 2026, with each source's own update date shown. Use these to judge broad value by year, then get a registration/trim/mileage-specific check before buying.
